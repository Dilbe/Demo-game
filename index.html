Demo Game is a from-scratch learning project, not a product: a small combat game built to practice plain JavaScript and HTML/CSS with no build tooling, and to work through a data-driven design pattern where stats, skills, monsters, dungeons, and quests are all just data objects. There's no backend, no accounts, and nothing for sale — just a repo growing through small, individually-finishable milestones (see DESIGN.md in the repository for the full list).
